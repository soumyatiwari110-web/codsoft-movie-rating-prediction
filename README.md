# 🎬 Movie Rating Prediction System

## 📌 Project Overview
This project predicts IMDb movie ratings using Machine Learning.

The system analyzes movie features such as:
- Genre
- Director
- Actors
- Duration
- Votes
- Release Year

and predicts the expected IMDb rating.

---

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- Flask
- HTML
- CSS

---

## 📊 Machine Learning Workflow

1. Data Collection
2. Data Cleaning
3. Feature Engineering
4. Label Encoding
5. Feature Scaling
6. Model Training
7. Model Evaluation
8. Deployment using Flask
